# Как открыть админку (Cursor по SSH)

## Почему на ПК не открывается 127.0.0.1:3847

Админка работает на НОУТБУКЕ. 127.0.0.1 на вашем ПК — это сам ПК, не ноутбук.

## Что делать

1. На ноутбуке в терминале Cursor: npm start (папка C:\Projects\rm_bot)
2. Внизу Cursor: вкладка Ports (Порты). Ctrl+J если панели нет.
3. Пробросить порт 3847 (Forward a Port), если его нет в списке.
4. У порта 3847 нажать иконку глобуса — откроется браузер на ПК с доступом к ноутбуку.
5. Вставить WEB_ADMIN_SECRET из .env, кнопка Применить.

## Зачем админка

Настройки бота, Redmine ключ, чаты — не в Telegram, а здесь.

Telegram: /task и @бот в чате.
